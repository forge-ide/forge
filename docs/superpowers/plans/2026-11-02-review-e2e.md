# Review End-to-End Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline, test first. No commits, pushes or PR creation until authorized.

**Goal:** Exercise the review loop and exact large-diff targets on both approved browser harnesses.
**Architecture:** Real daemon/fake-agent fixture plus shared UI flow and measurement contract; separate Linux Tauri/WebdriverIO and macOS browser/Playwright adapters. Test-only authenticated loopback bridge; production daemon remains Unix-only.
**Tech Stack:** Node built-in tests, WebdriverIO, tauri-driver, WebKitWebDriver, Playwright WebKit, ws, existing Solid/Vite/Tauri/Rust workspace.
**Spec:** ../specs/2026-11-02-review-e2e-design.md and approved decisions in project memory.

## Global Constraints

- Exact median-of-five first-file target <400 ms; maximum rAF delta <=32 ms. No relaxation without user approval.
- Linux real Tauri/WebKitGTK; macOS Playwright WebKit proxy explicitly labelled.
- Temporary private Forge data/runtime/config/HOME and git repo; fake-agent YAML writes whole files and replies over Forge MCP.
- No API/config schema/migration changes; no TCP in forged; no generated-file hand edits.
- Strict bridge Origin/capability checks; no production host fallback; no weakened security defaults.
- No milestone identifiers in code/comments/test headers. Keep this one branch/PR scoped to the harness and necessary host seam.

## Review Focus

- Wrong Origin/token and arbitrary socket/static paths cannot cross the test bridge.
- Failed starts, reconnects and cancellation close sockets/processes and preserve useful logs.
- A missing code render, incomplete scroll or missing reply cannot satisfy a check.
- Delayed frames and equality at the 400 ms boundary must fail the exact assertions.
- Browser-test imports/config cannot enable a network endpoint in the normal desktop build.

## Verification status

Linux locally: `GIT_CONFIG_GLOBAL=/dev/null just ci` passed (all Rust checks, 61 Vitest tests and 13 harness tests), followed by `just test-e2e` and `just test-sandbox` with the same environment. The real Tauri run used WebKitGTK 2.54.2 / Wry 0.57.1, measured openings of 100, 100, 100, 103 and 108 ms (median 100 ms), and a maximum scrolling frame of 20 ms. All six full-file scrolls reached their final line with at most 69 mounted code lines. All 23 sandbox tests passed.

Six mutation checks rejected removed Origin/capability checks, loosened timing boundaries, missing agent reply and unresolved state. Independent review findings were fixed with regression tests; the same GPT-6 Astra adviser closed the bridge security finding.

One earlier full run failed in the unchanged daemon startup test `stale_socket_is_replaced` when shutdown returned SIGTERM. Its targeted rerun and the final full run passed; no daemon changes were made.

macOS Playwright WebKit proxy execution is pending CI after publication. Both adapters and CI jobs are implemented; this is not evidence of a macOS pass or milestone completion. Nothing has been committed or published.
